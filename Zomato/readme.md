- In this practice session we are designing an Food delivery app like Zomato/Swiggy.

**Lets look at the breif working of the application**

- The application would have a list of resturants that the user would see.
- Each restaurant would have a menu, the menu would have the list of food items the restaurant would serve.
- A user would place orders.
- The order would be assigned to a restaurant and a delivery partner would also be assigned to a order.
- There would be a payment method that would be present in the system for the users to pay for their order.
