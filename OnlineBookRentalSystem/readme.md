**Question:**

We are designing a online book selling system.

**Briefly making the notes about what all the system would have**

- Things that we wil be focusing in the library management system is as follows:

1) The library management system should should show users the list of available books.
2) Each book would have information like the name of the book, the author name, price of renting the book, publisher, languages etc..
3) The book would also the status information about the availability of the book.
4) There would an admin user, who can add, delete and update the book in the library management system.
5) Users would select the book that they want to take on a rent and can complete the transaction for paying for bill through different type of payment methods.
6) We would also store in the information about the user like user name, user borrowed book, etc..
7) We should also take into fact about concurrent users trying to book on the same book.
